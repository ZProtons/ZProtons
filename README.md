### 🔎 About me

I'm 18, currently starting a cybersecurity internship, and studying Computer Engineering on the side. I don't build things to make them pretty — I build them to find out where they break, and I write down exactly how I broke them.

- 🧪 Currently: shipping something to GitHub every day — a lab, a tool, a writeup, or a fix
- 🎯 Focused on: web application penetration testing
- 📚 Learning path: self-directed labs + PortSwigger Academy + TryHackMe, documented as I go

### 🛠️ What I'm building

| Project | What it is |
|---|---|
| [**Web-Pentesting-Notes-B1**](https://github.com/ZProtons/Web-Pentesting-Notes-B1) | A maintained 61-chapter web pentesting guide — with its own build pipeline and CI that checks the repo stays consistent on every push |
